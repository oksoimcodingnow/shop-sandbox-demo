# Shop Sandbox: concept prototype

A clickable concept prototype made by a student team for a case-competition entry
(GrabSpark 2026). It shows how a small restaurant owner could see what the shop really keeps,
rehearse a decision, try it small and learn from the result.

- Everything is sample data: the shop, its prices, the suppliers and every figure are made up.
- It is not a Grab product and is not affiliated with or made by Grab or any delivery platform.
- One static page, no server, no tracking, no data collected.

Open it here: https://oksoimcodingnow.github.io/shop-sandbox-demo/
